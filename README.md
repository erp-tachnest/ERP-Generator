# 🎓 School ERP Generator

A modern, AI-powered School ERP platform designed to simplify administration, improve communication, and enhance student outcomes.

🔗 Live Design: https://www.figma.com/design/4BDUq7pGQkuQ9LAhd24ubn/School-ERP-Platform-Pages

---

## ✨ Features

- 👨‍🎓 Student Management System
- 📅 Attendance Tracking (Real-time)
- 🗓️ Smart Timetable Generator
- 📝 Exam & Result Management
- 💳 Fee Management System
- 💬 Parent-Teacher Communication Portal
- 📊 Analytics & Reports Dashboard
- 🇮🇳 NEP 2020 Compliant

---

## 🛠️ Tech Stack

- ⚛️ React + TypeScript
- 🎨 Tailwind CSS
- 🧩 Lucide Icons
- 🔄 React Router
- 💡 Modern UI/UX inspired by SaaS platforms
